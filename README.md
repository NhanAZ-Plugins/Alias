# Alias

Alias is a legacy PocketMine-MP plugin that lists player names associated with a recorded IP address. The original author is Ghast Noob.

## Compatibility

The manifest declares API `1.12.0`. This source has not been migrated to Axolotl-PM 5 and has no verified build or runtime test for that server. Do not install it on an Axolotl-PM 5 server.

## Data handling

The original implementation saves player IP addresses and name associations under the plugin data directory when a player joins. Review the code and applicable privacy requirements before using it on any compatible legacy server. The campaign has not tested its behavior on a legacy runtime.

## Project status

This repository is retained as a historical source reference. No new PHAR or release was produced during the Axolotl-PM 5 migration campaign. The repository has no license file, and redistribution rights have not been verified. The original source and manifest are unchanged.
